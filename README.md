# LegacyBench

A pre-registered, execution-verified evaluation of frontier models on legacy software
modernization. This repository currently holds the design brief and the harness for a
**$200 pilot**. The pilot does not rank models and makes no claim about which model is
best for modernization. It measures each model's real output ceiling, validates the
harness end to end, and produces the cost, time and variance numbers that a funded
study needs for its power analysis.

## What is here

| Path | What it is |
|---|---|
| `docs/00-benchmark-design-brief.md` | Design brief: construct, audit of the six originally proposed benchmarks, methods, statistics plan, cost envelope, the full-study prompt, the $200 pilot, open decisions. Appendices hold the cited research notes. |
| `docs/01-pilot-protocol.md` | The pilot protocol: tasks, arms, caps, budget, what is and is not claimed. |
| `prereg/PREREG.md`, `prereg/hash.sh` | Pre-registration text and the script that freezes it with a hash and git tag. |
| `tasks/pilot.yaml` | Task manifest: 16 Java 8 to 17 Maven repositories from FreshBrew, with size strata, baselines and licenses. Generated by `scripts/build_pilot_manifest.py`. |
| `legacybench/probe/ceiling.py` | Output-ceiling probe: a known-length, mechanically checkable generation per model. |
| `legacybench/solvers/` | `single_shot.py` (whole repository in one response, no tools) and `agentic.py` (shared minimal bash plus editor scaffold). |
| `legacybench/scorers/` | MigrationBench and FreshBrew gates: build, tests, test files unchanged, test count, class-file version, coverage guard. Pure logic in `gates.py`, sandbox plumbing in `java_migration.py`. |
| `legacybench/tasks.py` | Inspect task definitions `pilot_single_shot` and `pilot_agentic`. |
| `legacybench/prices.yaml`, `legacybench/ledger.py` | Dated frozen price sheet and the tokens-to-dollars, latency-decomposition ledger. |
| `legacybench/analysis/` | Power and minimum-detectable-effect formulas, paired and clustered estimators, pass@k and pass^k, Holm, the descriptive report. |
| `docker/`, `scripts/build_image.sh` | Sandbox image with JDK 8 and 17, offline Maven cache, repositories baked in read-only. No network at run time. |
| `.github/workflows/pilot.yml` | Manual workflow that runs one task on one model under a per-sample cost cap and uploads the logs. |

## Running

Nothing here runs without API keys and a Docker daemon. Unit tests run anywhere:

```bash
pip install -e ".[dev]"
pytest
```

Smoke-test the probe against Inspect's mock model (needs one-time network access so
tiktoken can download its encoding file; set `TIKTOKEN_CACHE_DIR` to reuse it offline):

```bash
inspect eval legacybench/probe/ceiling.py --model mockllm/model -T lengths=5
```

Real runs, in the order the protocol requires:

```bash
# 1. fill prices.yaml (Astra is blank), then freeze the registration
bash prereg/hash.sh

# 2. output-ceiling probe, one model at a time
inspect eval legacybench/probe/ceiling.py --model google/gemini-4-argon \
  --max-tokens 1048576 --reasoning-effort high --cost-limit 12

# 3. sandbox image (network needed at build time only)
bash scripts/build_image.sh tasks/pilot.yaml

# 4. arms
inspect eval legacybench/tasks.py@pilot_single_shot --model anthropic/claude-fable-5-1 \
  -T strata=S,M,L --cost-limit 9
inspect eval legacybench/tasks.py@pilot_agentic --model openai/gpt-6.1-sol \
  -T strata=S,M,L,B --cost-limit 1.5

# 5. ledger and descriptive report
python -m legacybench.analysis.report logs --out reports/pilot
```

On GitHub, the `pilot` workflow does steps 2 to 5 one (task, model) pair at a time
with the keys in repository secrets. A public repository gets the runner minutes free.

## What the pilot cannot claim

Any model ranking. Any confirmed or refuted hypothesis. Anything about COBOL or
mainframes. Inter-annotator reliability. Contamination status. The design brief
explains why each of these needs the funded study, and what that study costs.
