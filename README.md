# LegacyBench

An aggregate, execution-verified benchmark of frontier models on legacy software modernization.

Status: design phase. Nothing runs yet.

- `docs/00-benchmark-design-brief.md`: the design brief. It states what a rigorous benchmark must do, audits the six originally proposed sub-benchmarks (four dropped, two kept with fixes), names the raw material and tools, gives the statistical analysis plan, a cost envelope, the rewritten execution brief, and open decisions. Appendices hold the cited research notes.
